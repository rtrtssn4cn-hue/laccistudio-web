# Website audit — September 2026

Scope: laccistudio.com as served on 2026-09-26, the `laccistudio-web` repository (identical to live, tag `live-2026-09-26`), the Etsy shop, and the admin configuration.
Work branch: `audit-2026-09`. **Nothing has been published.** Pricing is in `PRICING-2026-09.md`; the admin is in `ADMIN_AUDIT.md`.

## 1. What was found

### How the site is built
- Static HTML, CSS and JS; content comes from `content/*.json` via `assets/js/boot.js`.
- Shop and customizer: `assets/js/cart.js` (≈1,300 lines). Checkout: Snipcart. Customer uploads: Uploadcare.
- Admin: Decap CMS at `/admin`, which commits to GitHub; a GitHub Action deploys to a Cloudflare Worker.
- Six pages: Home, Shop, Services, Gallery, About, Contact. No product pages (the shop opens a customizer pop-up), no FAQ page (FAQ sits on Contact), no policy pages.
- Eleven local copies of the site existed on this computer. None matched live. The only accurate source is the `laccistudio-web` repo (see `PROJECT.md`).

### Catalog reality
- **Etsy sells 4 product types** (11 listings): ceramic coasters (single $6.99 / set of 4 $19.99), 20 oz tumblers (name and pet photo, $19.99), 11 oz pet photo mug ($19.99), sublimation tee ($25.98–35.98).
- **The website shows 27 products**, plus 18 hidden. 22 of the 27 aren't on Etsy: hoodies, crewnecks, hats, beanies, aprons, totes, socks, license plates, ornaments, bookmarks and more. All use blank studio mockups rather than photos of finished work.
- Customizer options include materials and variants that may not be real offerings: coaster sandstone/cork/neoprene/acrylic/slate; tumbler 30/40 oz, glitter, holographic; mug enamel-camp, color-changing. **Needs owner confirmation.**
- One real review exists (Etsy, Aug 8 2026, a custom T-shirt, 5★).

## 6. Recommended product and category structure

With four real product types, broad category pages would be thin. Recommended:

- **Navigation:** Shop · Pet Gifts · Real Orders (once photos exist) · About · Custom Orders · [Shop Gifts]
- **Best Sellers** (homepage row, shop default order): Photo coasters (single / sets), 20 oz tumbler, pet photo mug, photo tee.
- **Pet Gifts:** pet photo coasters, pet tumbler, pet mug. All exist today, so the collection has 3+ products.
- **Seasonal collection** (one at a time): Christmas / holiday photo coasters now through mid-December. The Etsy Christmas coaster listing already exists.
- Do **not** launch For Her / For Him / Couples / Family / Birthday as separate pages yet. Use them as "Made for…" tiles that point into the same four products with example ideas.
- **Business / Bulk:** Custom Orders page only.
- Everything not producible today: set to hidden, not deleted.
