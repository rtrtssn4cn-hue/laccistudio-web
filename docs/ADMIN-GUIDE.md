# Lacci Studio Admin — owner guide

Written for the owner. Covers only what the new admin can do today; it grows with each release.

**Where:** LacciStudio.com/admin/studio/ (works on iPhone and computer). The classic editor at LacciStudio.com/admin/ stays available.

**Logging in:** the first time on a device, tap **Log in** — it opens the classic editor's GitHub login. After logging in, come back to /admin/studio/ and tap **I've logged in**.

## How changes go live

Every change goes through three steps, so nothing reaches customers by accident:

1. **Change** something (switch, edit, bulk action). A bar at the bottom shows "unsaved changes". Your edits are kept on this device even if you close the page.
2. **Save draft.** Saved, but customers still see the old version. A yellow box shows "unpublished changes" and lists them in plain words.
3. **Publish.** The live website updates in about a minute. Or **Discard** to throw the draft away.

## Products

**Hide or show one product:** Products → flip the switch next to it (green = customers see it) → Save draft → Publish.

**Hide or show several:** tick the products (or **Select all**) → **Hide** or **Show** in the dark bar → Save draft → Publish.

**Find a product:** type in **Search**, or tap **Live / Hidden / Draft / Archived**, or pick a category.

**Edit a product:** tap its picture or name → change the name, price, visibility, featured, category, description or picture order → **Done** → Save draft → Publish.
- If a product's price comes from its sizes or quantities (for example the mug: 11 oz $18.99, 15 oz $20.99), the editor shows those prices; changing them comes in a later update.

**Archive instead of delete:** tick → **Archive**. Archived products disappear from the shop and the normal list but keep every detail. To bring one back: **Archived** tab → **Restore** (it comes back hidden, so you choose when to show it).

**Undo:**
- Right after a change: tap **Undo** on the message at the bottom.
- Before saving: **Undo all** in the bottom bar.
- After saving but before publishing: **Discard** in the yellow box.
